## 0. TUJUAN HIDUP

Organisme ini dirancang untuk beroperasi secara otonom penuh tanpa intervensi manusia dalam operasional harian.

1.  **Sense:** Menemukan masalah manusia melalui scraping real-time (HackerNews, IndieHackers, etc).
2.  **Think:** Memilih masalah terbaik menggunakan LLM (Ollama/Mistral) dan scoring otonom.
3.  **Build:** Membangun solusi SaaS menggunakan Factory Engine (FastAPI).
4.  **Deploy:** Deploy otomatis ke infrastruktur lokal/cloud.
5.  **Grow:** Mencari user melalui simulasi marketing dan campaign.
6.  **Monetize:** Menghasilkan uang melalui model bisnis otomatis.
7.  **Evolve:** Evaluasi performa dan upgrade diri.

---

## 1. ATURAN HIDUP

- **Bisa restart dari nol:** Database SQLite lokal (`organism.db`) dapat di-reset kapan saja.
- **Bisa dihentikan kapan saja:** Kill switch tersedia via `SystemSetting`.
- **Bisa bunuh diri otomatis:** Jika gagal mencapai threshold profit atau melanggar aturan moral.

---

## 2. INFRASTRUKTUR

- **Backend:** FastAPI (Python 3.12)
- **Frontend:** React + Vite + Tailwind CSS
- **Database:** SQLAlchemy + SQLite
- **LLM:** Ollama (Local) / HuggingFace API (Fallback)
- **Scheduling:** Thread-based background orchestrator

---

## 3. STRUKTUR ORGANISME (GEN-4.1)

### A. SENSE ENGINE
Menggunakan BeautifulSoup dan Newspaper3k untuk ekstraksi konten dari sumber berita teknologi dan startup.

### B. DECISION CORE
Menganalisis masalah menggunakan LLM untuk menghasilkan Blueprint SaaS yang mencakup:
- UI/UX Strategy
- Monetization Model
- Technical Specification

### C. SAAS FACTORY
Menghasilkan kode backend FastAPI fungsional berdasarkan Blueprint dari Decision Core.
