## 3. STRUKTUR ORGANISME (GEN-4)

### A. SENSE ENGINE (INDRA)
- **Tugas**: Mengumpulkan masalah manusia menggunakan Playwright.
- **Sumber**: Reddit, HackerNews, IndieHackers, ProductHunt.
- **Pipeline**: Scrape -> Clean -> Filter Noise (LLM) -> SQLite.

### B. DECISION CORE (OTAK)
- **Proses**: TF-IDF vectorization + KMeans clustering.
- **Formula Scoring**: `(keluhan * 0.4) + (emosi_negatif * 0.2) + (otomasi * 0.2) + (uang * 0.2)`.
- **Output**: Idea candidates dengan blueprint teknis mendalam.

### C. SAAS FACTORY (RAHIM)
- **Tugas**: Membangun produk MVP lengkap secara otomatis.
- **Output**: Direktori produk berisi Backend FastAPI, Frontend React, Dockerfile, dan docker-compose.yml.

### D. MONETIZATION & GROWTH
- **Growth**: Menghasilkan konten pemasaran otomatis (Twitter/Reddit) dan simulasi trafik.
- **Monetization**: Simulasi pendapatan berdasarkan konversi trafik nyata ke log pendapatan.

### E. EVOLUTION ENGINE
- **Evolusi**: Menganalisis log trafik dan pendapatan untuk menyesuaikan bobot Decision Core secara dinamis di `system_settings`.

### F. IMMUNE SYSTEM (ANTI GILA)
- **Aturan**: Max iterasi per tugas, timeout keras, dan pemantauan resource untuk mencegah loop tak berujung.
