# 🧬 BLUEPRINT TEKNIS - GEN-4
## Organisme SaaS Otonom: Evolusi Brutal

### 0. TUJUAN HIDUP
- Menemukan masalah manusia (Sense)
- Memilih masalah terbaik (Decision)
- Membangun solusi (Factory)
- Cari user & Hasilkan uang (Growth & Monetization)
- Evaluasi & Upgrade diri (Evolution & Immune)

### 1. STACK TEKNOLOGI
- **Backend:** FastAPI (Python 3.11)
- **Frontend:** React + Tailwind + Vite
- **Database:** SQLite + SQLAlchemy
- **ML/AI:** Scikit-learn, NLTK, LLM (Ollama/HF)
- **Scraper:** Playwright (Dynamic Mode)

### 2. ENGINE PIPELINE
1. **SENSE:**
   - Scrape (HN, Reddit, PH) -> Raw Data.
   - Noise Filter (LLM) -> Clean Data.
2. **DECISION:**
   - TF-IDF + KMeans Clustering.
   - Weighted Scoring: `(volume * 0.4) + (neg_emotion * 0.2) + (automation * 0.2) + (revenue * 0.2)`.
3. **FACTORY:**
   - Code Generation (FastAPI Backend, React Frontend, Dockerfile).
4. **GROWTH:**
   - Multi-stage content generation (Pre-launch, Launch, Post-launch).
5. **EVOLUTION:**
   - Self-tuning weights based on performance metrics.
6. **IMMUNE:**
   - System health monitoring & runaway process protection.

### 3. DATA MODELS
- `problem_raw`: Input mentah dari scraper.
- `problem_clean`: Data terfilter siap analisis.
- `idea_candidates`: Hasil scoring Decision Core.
- `products`: Catatan produk yang berhasil dibangun.
- `engine_logs`: Saraf pusat monitoring.
