## 🚀 GETTING STARTED

1. **Install Dependencies:**
   ```bash
   pip install -r backend/requirements.txt
   npm install
   ```

2. **Run Backend:**
   ```bash
   python3 -m backend.main
   ```

3. **Run Frontend Dashboard:**
   ```bash
   npm run dev -- --port 8080
   ```

4. **Verify System:**
   ```bash
   python3 verify_organism_ui.py
   ```
